# 服务器、远程命令与文件

Desktop“服务器管理”维护服务器目录、人工与 AI 连接凭据、项目关联、用户授权、AI 委托、策略及会话。凭据配置与账号验证走软件入口；MCP 不用于索取或显示秘密。

## 确定资产与会话

已知服务器 ID 时使用 `server_context_get`；未知时小页 `server_assets_list`。核对目标主机、项目、连接方式、执行就绪状态及有效 AI 策略，避免在同名主机上执行。

复用本任务在同一项目已打开的可用会话；否则 `server_session_open`，保存 `remote_session_id`。跨项目时显式选择获准 `project_id`，所有后续命令、文件、结果读取和关闭都使用该项目。

隔离模式、账号权限、路径、命令类别和环境变量限制以当前上下文为准。高权限账号通过验证后仍具有真实系统权限，不能把验证成功当成操作影响已缩小。

## 结构化远程命令

`server_command_execute` 使用独立的 `executable` 与 `args`。当前云端目录要求绝对 POSIX 可执行路径，例如 `/usr/bin/uname`，参数另放数组；实际 schema 若不同，以会话为准。

- 工作目录用支持的 `cwd`，环境变量仅使用策略允许项。
- 当前云端 `timeout_ms` 上限为 30,000，不能照旧版本地上限填 120,000。
- 不把整条命令字符串写进 `executable`，不依赖 PATH 查找；不通过 Shell 包装、拼接或类别标注绕过策略。
- 输出在执行端尽量筛选为计数、状态、目标时间段或必要错误。只有当前权限和真实命令支持时才采用相应过滤，不能虚构工具参数。

有的调用会等待并直接返回终态。若 `is_complete=false`，保留原 `remote_session_id` 和 `command_id`，用 `server_command_result_get` 查询状态与分页输出；无需新开会话，不重复执行。

## 文件操作

- `server_file_read` 读取明确文件，核对实际返回内容与哈希。
- `server_file_patch` 使用最新 `expected_sha256` 和结构化替换 / 追加 / 前置操作。替换次数按真实意图控制，不能把替换一处误设为所有匹配。
- `server_file_write` 是完整内容写入，只在任务需要且已有完整基线时使用；改一处优先补丁。

当前 `server_file_read` schema 没有行范围、offset 或 limit 字段，不能自行加参数。大文件超出预算时，改用已获准且能限制输出的结构化命令或其他真实支持方式；不能为了读大文件关闭安全预算或暴露整份敏感配置。

补丁哈希冲突说明目标文件已变，重新读取必要基线并合并。不能换成整文件覆盖来绕过冲突。

## 完成、清理与节省 token

验证命令终态、退出码、关键输出与实际目标；文件修改回读必要内容。未知结果时先保留会话与命令 ID 核对，不因超时直接重发。

任务结束关闭本任务创建的空闲会话并确认结果，避免占用配额；不会关闭其他任务的会话。报告服务器标识、命令 / 文件范围、结果、验证与已关闭会话。

通过复用会话、读取必要输出、局部文件补丁及合理轮询减少往返；这些方法不能替代目标确认和写后验证。
