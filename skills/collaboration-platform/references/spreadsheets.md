# Excel 与表格数据

用于 Desktop“表格管理”及 `sheet_*` 工具。平台工作簿的 `document_id`、工作表的 `sheet_id` 和 A1 区域需分别确定。

## 从结构缩小范围

已知工作簿 ID 时先 `sheet_get` 了解工作表、已用行列、冻结与合并信息；它不返回单元格。需要查找工作簿才 `sheet_list`，需要目录或支持函数与限制才 `office_context_get(kind=excel)`。

用 `sheet_find` 定位值或公式，再 `sheet_range_read` 读取必要表头、关键列和目标区域。显式传 `sheet_id` 与 `range`，避免依赖默认整表范围。当前一次区域读取最多 5,000 格，大表按任务范围分块。

公式格应同时核对公式原文、计算值和错误。值可能是已算好的结果，不能把结果当公式；日期、百分比、货币与文本编号结合单元格类型和显示格式解释。

## 计算与编辑

| 任务 | 使用方式与注意事项 |
| --- | --- |
| 新建工作簿 | `sheet_create`，必填名称、Markdown `description`；可用 CSV 带入首表数据 |
| 改名称、说明、目录 | `sheet_update`，不修改对象 AI 编辑开关 |
| 增删工作表 | `sheet_add` / `sheet_remove`，至少保留一张；删除需在用户授权范围内 |
| 改工作表配置 | `sheet_config_set`；改名可能重写其他表的公式引用 |
| 局部写入 | `sheet_range_set`，只指定计划修改的区域；采用当前返回结构组织 `values` 或 `cells` |
| 插删行列 | `sheet_rows_*` / `sheet_cols_*`；核对移动引用和删除造成的 `#REF!` |
| 样式与合并 | `sheet_style_set` / `sheet_merge_set`；合并区域集合是整体替换，需保留既有未涉及区域 |
| CSV 导入或导出 | `sheet_csv_set` / `sheet_csv_get`，仅在确实需要整表文本交换时使用 |

`sheet_range_set` 可能清空指定区域内未被 `values` 覆盖的格；不要为修改几个格而指定整个工作表。先缩小写入矩形，或按实际 schema 用 `cells` 精确修改。保留区域内原有公式与有效数据。

按人类输入规则解释 `values` 中的字符串：以等号开头可成为公式，带前导零的编号需保持文本。写后核对实际 `kind`、值与公式，不能只核对界面字符串。

写入后通常自动重算受影响公式。先确认平台支持所需函数；不支持时使用获准脚本进行计算并解释方法，不把未计算或错误值报告为正确汇总。公式、脚本与 SQL 的统计口径应一致，特别是空值、重复项、时间范围和单位。

## 全表替换与文件交换

`sheet_csv_set` 是整张工作表替换，不能当成增量合并。CSV / TSV 不保留 Excel 的完整样式、图片、多表和复杂结构。需要保留这些内容时优先区域编辑，文件导入 / 导出走 Desktop 的 `.xlsx` 入口。

`sheet_csv_get(formatted=true)` 返回显示格式，`false` 返回存储值；按数据交换用途选择，避免误读百分比、日期和金额。大量数据的筛选、聚合与去重尽量在程序中完成，给 AI 结构、口径、关键结果和必要样本。

## 回读与 token 节省

从同一工作簿最新修订写入，回读修改区域、关联公式与关键合计；不要为一次局部修改重新下载所有工作表。报告工作表、A1 范围、新修订、统计口径及核对结果。

推荐路径：结构 → 目标搜索 / 小区域 → 程序或公式计算 → 局部写入 → 关键结果回读。只看样本不能证明全表无误，完整审计任务仍须处理所有必要数据。
