# Local API 与服务管理

用于软件实例管理，不假设平台 MCP 提供服务初始化、授权、备份或升级接口。有获准 UI / 管理工具时使用真实能力；没有时给出页面、字段、核对步骤和可确认的完成标准。

## 按问题选择模块

| Local API 模块 | 操作与验证 |
| --- | --- |
| 服务状态 | 查看进程、就绪、授权、连接检查与活动连接；启动 / 停止 / 重启后核对实际状态 |
| 初始化与恢复 | 选择数据目录、本机 / 内网配置、TLS 和自动启动；跟踪激活、迁移与失败恢复 |
| 客户端连接 | 生成可访问地址、证书指纹与连接信息；查看租约与额度，吊销确定不再需要的连接 |
| 用户与权限 | 添加、启停有云端身份的实例用户，区分实例资格与云端项目成员 |
| 存储与备份 | 检查数据库 / 附件容量，创建备份，完整性与恢复预检，迁移换机 |
| 服务器安全 | Vault 健康与恢复材料、活动远程会话、配额及保留期 |
| 诊断日志 | 宿主 / 服务检查、事件与实时连接、脱敏摘要与报告 |
| 关于与更新 | 查看版本、契约和兼容影响，按真实渠道入口预检、升级或满足条件的回滚 |
| 云端账号 | 登录、查看设备 / 权益、更新账号会话及授权状态 |

先读取与当前问题相关的状态，不固定导出全部日志、用户与审计记录。

## 备份范围

| 对象 | 由什么方式保障 |
| --- | --- |
| 本机数据库、附件、配置与实例资料 | 按 Local API 当前备份选项与预检清单确认 |
| 云端项目及协作内容 | 云端服务维护；本机实例备份不包含云端最新内容 |
| 本机源码仓库 | 仓库自身的文件备份与 Git；平台目录快照不是源码备份 |
| 外部服务器、数据库、Redis 业务数据 | 对应目标系统的备份机制，不能用平台实例备份代替 |
| 实例迁移包 | 迁移本机身份、数据及凭据保护材料，按软件说明设置口令并核对范围 |
| Vault 恢复包 | 凭据保护恢复材料，与完整实例迁移包用途不同 |

## 备份、恢复与换机

创建备份时，记录实例、目录、版本、时间、附件范围和完整性结果，保留实际备份产物标识。预检通过只代表具备下一步条件，不能说恢复已完成。

恢复前核对目标实例、当前数据目录、Schema / 版本兼容、实际覆盖范围与用户授权。需要保留当前状态时先做可用备份；不要把恢复或初始化当作普通的连接故障修复手段。

迁移时使用软件支持的实例迁移流程，导出后检查产物范围，在目标机器预检、导入、重新登录并确认服务就绪、成员连接和必要对象。单纯移动可执行文件目录不等于迁移实例身份与数据。

凭据、迁移口令及恢复材料通过软件支持的秘密输入和保管方式处理，不粘贴到对话、命令历史或公开报告。只报告脱敏标识、位置及验证结果。

## 升级与异常恢复

升级按真实发行渠道及当前入口执行，先确认目标版本、兼容影响、必要备份和迁移条件。不能因为页面介绍过更新功能，就声称一定存在在线更新或任意版本回滚。

修复时优先处理已证实的问题。保留配置、数据目录、实例身份及配套运行文件；没有明确授权和必要性，不删除数据库、重置 Vault、重建实例或清理用户数据。

## 完成与节省 token

以实际就绪状态、恢复结果、连接检查和必要数据核对证明完成。报告实例、执行动作、产物、验证和待处理项；UI 操作没有实际执行时明确区分操作指引与已完成工作。

先取状态与错误摘要，按请求 ID、时间和模块限定日志；需要证据时保留原文件供查验，向 AI 提供相关片段，避免整套日志与备份内容反复进入上下文。
