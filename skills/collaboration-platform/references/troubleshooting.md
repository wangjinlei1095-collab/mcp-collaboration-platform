# 故障定位与恢复

先取得模块、目标 ID、时间、软件 / 服务版本、错误码与请求或运行 ID。只读与当前问题有关的状态和脱敏日志，避免用重复登录、重连、提权或重发写操作代替诊断。

| 现象或错误 | 优先核对 | 有效下一步 |
| --- | --- | --- |
| Desktop 无法连接 Local API | 就绪状态、真实地址、端口、TLS 与指纹；异机是否误用回环地址 | 在“服务连接”和 Local API“服务状态 / 诊断日志”定位，不重建实例 |
| 能登录但连不上实例 | 云端账号、实例访问资格、本机成员与服务授权 | 按明确错误处理实例资格，不能把登录成功当成连接许可 |
| 能连接但看不到项目 | 正确云端账号、项目成员、默认项目与授权白名单 | 刷新并验证具体项目；不要创建同名项目作为替代 |
| Skill 已加载，但没有调用平台 MCP | 当前会话的实际工具与延迟发现能力，客户端配置是否在本聊天生效 | 按 [MCP 调用约定](mcp-contract.md) 主动发现与只读排查；读取 Skill 不等于 MCP 已连接，不直接转去操作界面 |
| MCP 配置无法加载 | 所选客户端与传输、用户级 / 项目级配置、启用状态、实际程序路径、网关运行状态、启动错误 | 按实际配置来源定位；需要重新导出时用对应客户端模板，保留其他服务配置 |
| HTTP 网关不可达 | 本机系统、动态端口、随机路径、重启后的地址、客户端专属端点 | 复制最新完整本机地址；检查 WSL / 容器 / 远程窗口边界，不改公网或旧 SSE |
| 工具缺失、入口不可见 | 是否完成工具发现、平台整体或单个模块缺失、版本、模块开关、套餐、权限预设、能力选项、对象授权 | 先发现再诊断；确认缺失后说明入口与证据，配置或授权变更后刷新，不猜工具名 |
| `MCP_PROJECT_NOT_AUTHORIZED` 或项目选择错误 | 请求项目是否在当前白名单，ID 是否确属目标 | 用已授权的正确项目；需要其他项目时由用户调整白名单 |
| `SCOPE_VIOLATION` / `CONTENT_ACCESS_DENIED` | 当前工具范围、项目成员和对象权限 | 报告不可访问的具体范围，不读取或泄露被拒内容 |
| `AUTH_REQUIRED` / `SESSION_EXPIRED` | Desktop 账号与会话是否仍有效 | 恢复软件登录与连接，重新验证目标；先核对旧写入结果再继续 |
| `VALIDATION_FAILED` / `REQUEST_TOO_LARGE` | 未声明字段、ID 类型、版本漂移、单项或结果预算 | 按错误改参数、拆内容或缩页，不原样重试 |
| `QUERY_TOO_LARGE` | 内容根或子树遍历范围是否过大 | 改读更近分支或逐层定位，不能只反复缩分页 |
| `VERSION_CONFLICT` 或文件哈希不符 | 目标最新内容是否被他人修改 | 只刷新相关部分并合并；确有意图冲突才请用户选择 |
| `LOCAL_ASSET_SESSION_LIMIT_REACHED` | 实例有效配额、本任务已有资产会话与未决操作 | 复用或关闭本任务闲置会话，等待租约释放；重登不解决容量 |
| `MCP_CONNECTION_LIMIT_REACHED` | 网关客户端连接池及当前启用实例 | 关闭确定属于本任务且不再需要的连接，或由管理员处理配额 |
| `DB_SESSION_NOT_OPEN` / `DB_SESSION_EXPIRED` | 会话是否属于原 MCP / 项目，执行端与租约是否有效 | 核对旧语句结果后再按需开新会话，不重新发送未知写入 |
| `DATABASE_METADATA_SCOPE_DENIED` / `DATABASE_SCOPE_DENIED` | 库、Schema、表与外键范围，结构 SQL 是否满足约束 | 限定 Schema / 表、拆支持的结构查询；不是登录故障 |
| `DB_RESULT_PERSIST_FAILED` 或执行超时 | 原语句 / 命令 / 运行 ID、目标实际变化及审计 | 保留原 ID 核对结果，不再次执行相同写入 |
| 脚本或流程无法启动 | 真实 Desktop、随包运行时、依赖、目录执行与 AI 委托、引用脚本权限 | 修复实际缺项；参数按声明提供，图按 `runnable_reason` 修正 |
| Redis 某命令被拒绝 | Key / DB / 频道、操作类别与专用工具 | 单条拒绝不能证明全连接只读；指标用专用入口 |
| 返回空页或不完整 | 游标、快照、终态、截断、消息缺口 | 按接口语义继续必要页或合理等待，不把空页或样本当完整 |

## 控制重试的范围

只读临时故障可按返回的可重试提示和恢复迹象有限重试，适当拉开间隔。参数、权限、对象范围、配额或版本未变化时，相同请求不会因频繁重试变正确。

有副作用的调用优先查询已有运行、语句或命令状态；没有可用状态且仍无法确定是否执行时，说明未知状态与核对入口，停止重复写入。取消或断线不等于回滚。

## 最小故障报告

提供目标模块与脱敏对象标识、发生时间、错误码 / 请求或运行 ID、预期与实际、已证实原因及下一步。日志只给相关片段；完整材料可作为本机证据保存，不在回复里重复粘贴。

需要反馈时使用 Desktop“意见反馈”，附步骤与必要截图 / 脱敏摘要；使用实际获准能力提交，未执行就明确说明准备了什么。恢复后完成一次目标读取或本任务的必要验证，不用无关生产写入测试连接。
