# mcp协作平台 1.0.0

**把项目、文档、表格、业务导图、代码上下文、自动化测试和运维资源放在同一套协作环境中，让成员与 AI 围绕同一个项目开展工作。**

你可以在 Desktop 中直接操作，也可以通过 MCP 接入 AI 工具，使用“**交给 AI 或复制 ID 给 AI**”的方式，让 AI 读取项目背景、编辑内容、编写脚本、执行测试，或处理已授权的服务器、数据库与 Redis 任务。

本目录为 **Windows 64 位 1.0.0 发行包**，包含 Desktop 和 Local API。

## 平台组成与适用场景

### 各部分如何配合

| 部分 | 主要职责 | 谁会使用 |
| --- | --- | --- |
| **Desktop 桌面客户端** | 日常项目协作、内容编辑、开发上下文、脚本与流程测试、运维资源操作，以及本机 MCP 接入。 | 项目负责人、产品、研发、测试、运营及运维成员。 |
| **Local API 本地服务** | 管理服务实例、连接资格、本机存储、备份恢复、安全配置和诊断，为 Desktop 提供本地服务连接。 | 自己搭建服务的个人用户、团队实例管理员。 |
| **云端服务** | 提供账号与权益、云端项目和内容协作等能力。此发行包已预设连接地址。 | 通过软件登录后使用。 |
| **外部 AI 工具** | 通过 MCP 获取获准的项目与工具，在用户要求和授权范围内执行任务。 | 希望借助 AI 写内容、开发、测试或运维的成员。 |

个人可以在同一台电脑运行 Local API 与 Desktop；团队可以由管理员维护 Local API，多名成员通过各自的 Desktop 连接。连接本地服务后，仍需登录正确的云端账号并具备相应项目权限。

### 可以完成哪些工作

| 工作方向 | 平台提供的能力 |
| --- | --- |
| 产品与项目管理 | 整理产品定位、项目目标、范围、成员、版本与里程碑，统一团队和 AI 的工作背景。 |
| 知识与内容协作 | 编辑富文本文档和多工作表表格，维护版本、审计、授权及内容关联。 |
| 业务与研发梳理 | 用项目导图表达功能、规则和验收，用开发导图连接目录、符号、逻辑线与项目规则。 |
| AI 辅助开发 | 向 AI 提供准确的项目引用、源码位置、安全边界和 Skills，配合本机 IDE 完成代码修改与验证。 |
| 自动化与测试 | 编写参数化 Python 脚本，组合多节点流程，进行调试、断点检查和压力测试。 |
| 运维与数据处理 | 管理服务器终端、关系型数据库、Redis，以及供 AI 使用的独立账号、操作策略与会话。 |
| 服务管理 | 初始化实例、管理用户与连接额度、备份恢复、迁移换机、诊断与版本维护。 |

## 发行文件与安装入口

### 运行环境

- Windows 10 或更高版本，64 位系统。
- Microsoft Edge WebView2 Runtime，用于显示桌面界面。
- 能访问本包预设云端服务的网络；连接团队 Local API 或其他资产时，还需能够访问对应地址。
- 使用 AI 时，另行准备支持 MCP 的 AI 工具及其可用模型。平台中的 MCP 接入用于连接工具，模型账号与订阅由所选 AI 工具提供。

### 目录说明

```text
1.0.0/
├─ README.md                 本文：软件功能与上手介绍
├─ desktop/                  日常工作客户端
│  ├─ platform-desktop.exe   Desktop 主程序
│  ├─ platform-mcp.exe       供 AI 工具连接的本机 MCP 程序
│  ├─ runtime/               Python 运行时资源
│  └─ ...setup.exe           Desktop 安装程序
└─ local-api/                本地服务与管理程序
   ├─ platform-api.exe       带管理界面的 Local API
   ├─ platform-server.exe    无界面服务程序
   ├─ license-payload.bin    程序运行所需配套文件
   ├─ platform.yaml.dist     配置示例
   └─ ...setup.exe           Local API 安装程序
```

| 组件 | 安装与运行 |
| --- | --- |
| Desktop | 运行 [Desktop 安装程序](desktop/platform-desktop-windows-amd64-1.0.0-setup.exe)，或直接运行 [platform-desktop.exe](desktop/platform-desktop.exe)。便携运行时保留同目录的 `platform-mcp.exe` 和 `runtime/`。 |
| Local API | 运行 [Local API 安装程序](local-api/platform-local-api-windows-amd64-1.0.0-mcpcollapi2-setup.exe)，或运行 [platform-api.exe](local-api/platform-api.exe)，在管理界面完成配置。 |
| 无界面服务 | 有无人值守需求时使用 [platform-server.exe](local-api/platform-server.exe)，按实际部署配置运行。不要与管理界面程序同时使用同一数据目录。 |

Local API 运行时需保留配套的 `license-payload.bin`。升级时保留已有配置、数据目录和实例身份；移动程序目录与迁移实例是两件不同的事。两个组件目录中的 `SHA256SUMS.txt` 和清单文件可用于核对发行文件。

## 第一次使用

**自己搭建服务：**

1. 启动 Local API，登录云端账号。在“初始化与恢复”选择可读写的数据目录，设置本机或内网部署方式并保存。
2. 等初始化完成，在“服务状态”确认服务就绪、授权有效、连接检查通过。
3. 团队使用时，在“用户与权限”添加并启用成员；通过“客户端连接”提供成员实际可访问的连接信息。

**开始日常工作：**

1. 启动 Desktop，注册或登录云端账号。已有团队服务的成员可以直接从此步骤开始。
2. 到“服务连接”使用本机默认服务，或粘贴管理员提供的 Local API 连接信息，核对地址与证书指纹后连接。
3. 在“产品与项目”创建或选择项目，并给协作成员配置适当角色。
4. 按工作需要打开文档、表格、项目导图或开发导图。先保存一项简单内容，重新打开确认保存结果。
5. 需要 AI 时，在“设置 → AI 接入”选择项目、能力与客户端，生成配置并接入 AI 工具。

其他电脑连接 Local API 时，应使用实际 IP 或域名；`127.0.0.1` 只指向当前电脑，`0.0.0.0` 是监听配置值。需要逐步操作图解时，进入 Desktop 的“使用说明”。

## Desktop 功能介绍

本节介绍 Desktop 的以下 16 个页面。部分操作需要先启用对应模块、选择项目或获得授权；界面会根据账号、角色和本机显示设置提供可用入口。

### 1. 云端登录

- 注册账号、登录账号，按当前云端流程完成邮箱验证码等验证。
- 使用预设云端服务建立账号会话，登录后继续连接 Local API。
- 云端身份、实例访问资格和项目成员权限分别管理，登录成功后仍需完成服务与项目选择。

### 2. 工作台

- 从“继续工作”返回最近打开的项目和内容，或通过快捷入口新建工作对象。
- 管理最近访问和收藏，移除记录或清空本机访问历史。
- 查看当前会话中的待处理通知、保存冲突、运行结果和失败任务。
- 查看服务连接、实时事件、本机 MCP、授权、租约与后台任务等状态。
- 配合顶部项目选择、快速查找、侧栏分组和固定常用入口，快速切换工作。

### 3. 服务连接

- 使用本机默认服务，或导入 Local API 生成的完整连接信息。
- 检查地址、网络、TLS、证书指纹、实例、版本和授权状态。
- 保存、切换、删除本机连接配置，刷新连接状态并按提示重新登录或重连。
- 对自签名证书按连接核对信任；对团队内网部署使用相应连接策略。

### 4. 产品与项目

- 管理产品名称、问题、目标用户、核心价值、业务目标、范围、类型和阶段。
- 在产品下创建、编辑和选择项目，维护目标、上下文与当前修订。
- 管理拥有者、编辑者、只读成员等项目协作角色。
- 建立产品版本与里程碑，填写目标、日期和验收标准，查看进度摘要。
- 从项目主页进入已关联资源，快捷创建内容、打开导图或绑定代码目录。
- 复制产品、项目 ID 或 Content ID，向 AI 提供明确的工作对象和版本引用。

### 5. 文档管理

- 建立多层目录和富文本文档，编辑名称、用途说明与正文，拖动文档调整归类。
- 使用标题、大纲、字体、颜色、段落、列表、引用、代码块、链接、图片、表格和分页等编辑能力。
- 调整表格行列、合并拆分、边框与底色；设置图片宽度、对齐与替换文字。
- 使用查找替换、撤销重做、全屏、纸张方向和页边距等工具。
- 导入 `.docx` 并查看预检提示，导出 `.docx` 供外部使用。
- 查看版本、变更差异、人工与 AI 审计，按页面入口恢复历史或处理保存冲突。
- 配置目录授权和文档“允许 AI 编辑”，使用“交给 AI 或复制 ID 给 AI”完成整理、改写、补充和审核。

### 6. 表格管理

- 新建工作簿，新增、重命名、排序和删除工作表，按目录管理表格。
- 输入数据与公式，通过公式栏编辑，使用当前支持的函数计算与汇总。
- 设置字体、文字色、填充色、边框、对齐、换行、数字格式和小数位。
- 插删行列、合并单元格、冻结位置，使用查找替换及图片插入。
- 导入、导出 `.xlsx`；按当前工作表导出 CSV，或将 CSV 导入指定位置。
- 查看版本与审计、历史恢复、保存状态及冲突，管理目录授权和“允许 AI 编辑”。
- 将表格 ID、工作表、数据区域和统计口径交给 AI，完成整理、公式编写、汇总与结果核对。

复杂 Excel 函数、宏和特殊版式的兼容情况，应结合导入预检与实际计算、导出结果确认。

### 7. 项目导图

- 建立导图文件夹、思维导图或流程图；使用初始模板或多行粘贴批量建立层级。
- 新增、编辑、移动和折叠节点，管理节点类型、父子关系、坐标与展示名称。
- 维护连线、关系类型、业务线、颜色和说明，显示或隐藏关联线。
- 为节点编写 Markdown 说明，使用预览、源码、分栏、全屏等编辑方式。
- 关联子导图、文档、表格区域和流程记录，在不同工作对象之间跳转。
- 使用平移、缩放、全图定位、自动布局和全屏浏览复杂结构。
- 复制导图或节点引用，让 AI 在指定子树内补充功能、业务规则、测试点与验收说明。

### 8. 开发导图

将项目与本机源码位置、研发规则和逻辑结构对应起来，主要包含以下子模块：

| 子模块 | 功能 |
| --- | --- |
| 本机目录绑定 | 选择项目目录、核对指纹与 Git 状态、验证绑定，手动刷新目录。 |
| 目录树与符号索引 | 浏览目录、文件和符号，建立索引任务，跟踪进度、取消或处理失败任务。 |
| 源码位置与预览 | 查看路径、哈希、行范围，预览或复制源码，跳转 VS Code；维护显示别名、备注、隐藏和索引排除项。 |
| 内容关联 | 将目录或符号关联到知识内容，查看主关联，避免代码位置与业务说明脱节。 |
| 逻辑线导图 | 按功能组织节点和边，关联真实符号或独立节点，维护说明与来源；支持草稿、发布、驳回、归档及恢复。 |
| AI 安全边界 | 维护路径、工具、源码读取、网络、命令、数据库等策略和预算，比较版本并按角色审批发布。 |
| AI 配置集 | 选择安全边界版本，组合并排序多个 Skills，保存草稿、审批和发布。 |
| Project Skills | 维护项目规则、路径范围、任务约束、优先级与验证命令，预览修改并按角色审批。 |
| 数据库脱敏快照 | 导入表、字段与关系等结构描述，以只读快照表达数据模型，并关联目录节点。 |
| 目录快照历史 | 查看、比较历史快照与新鲜度，按权限发布、归档或恢复；管理未关联目录的项目资源。 |

本模块提供开发上下文。AI 修改代码和执行构建、测试时，仍使用其本机仓库与命令能力；发布平台快照不等于 Git 提交或推送。数据库结构快照也不等于连接真实数据库执行查询。

### 9. 脚本管理

- 按多层目录保存和组织 Python 脚本，维护名称、用途、参数说明及其他说明。
- 编辑并保存源码，查看参数配置、运行配置、版本和审计；部分显示模式需先进入维护模式。
- 用 JSON Schema 描述参数类型、默认值、必填项和限制，运行时生成输入表单，也可导入 JSON 参数。
- 使用随包 Python 运行时，查看依赖并按包名与版本安装所需包。
- 查看可用数据库、缓存连接及其 ID，通过 `platform_sdk` 使用参数、日志、结构化结果、连接和压测能力。
- 按授权使用直连或受控代理连接方式，设置运行超时与并发。
- 单次执行、取消运行，查看 stdout、stderr、日志、结果、错误、QPS 与延迟指标。
- 从历史记录核对当时的脚本修订、源码、参数、发起方和结果；将脚本交给 AI 修改或按指定参数运行。

脚本实际运行需要真实 Desktop 与相应目录执行权限；取消运行不会撤销已经写入外部系统的数据。

### 10. 流程测试

- 建立流程目录和流程，关联项目，按当前项目或全部流程查找。
- 从可执行脚本应用最小串行模板；复杂图结构可交给 AI 通过 MCP 编辑。
- 使用开始、结束、脚本、分支、延时、断言和人工节点，按连线编排执行过程。
- 配置常量、公共参数与上游结果映射；公共参数可按运行、虚拟用户或调用生成。
- 编写流程 Markdown 说明，记录前置条件、数据来源和结果解释。
- 调试运行，设置断点，查看变量、修改暂停变量、继续、单步或终止。
- 查看流程与节点实时输出、运行历史、失败位置、版本及运行结果。
- 进行并发压力测试，分析请求量、错误、QPS、耗时和延迟分位数。
- 通过目录授权、项目绑定及底层脚本权限，控制成员和 AI 的编辑、执行与观察范围。

流程的复杂图编辑按完整节点和连线保存；只有脚本节点执行 Python。建议先跑通单次调试，再逐步增加压测规模。

### 11. 服务器管理

- 按目录组织服务器，维护主机、端口、平台、传输、状态和身份指纹。
- 配置人工连接凭据与 AI 连接凭据，按项目关联服务器或服务器目录。
- 打开真实远程终端，使用多会话标签、全屏、复制粘贴、会话接管、重连和关闭。
- 管理用户连接权限、MCP 发现与观察权限、AI 委派以及服务器管理员。
- 配置 AI 路径、命令类别和环境变量策略；按支持的连接方式配置、下发或验证 AI 账号。
- 设置单服务器、单用户和实例的会话配额，查看活动会话与运行状态。
- 让 AI 在明确的服务器和路径范围内执行结构化命令、读写文件，并按命令 ID 查询最终输出。

不同平台和传输方式的终端与验证能力，以页面实际能力提示为准。账号验证通过后，AI 仍使用该账号的真实权限；使用 root 等高权限账号时，平台策略不会将其自动变成低权限系统账号。

### 12. 数据库管理

- 管理 **MySQL / MariaDB、PostgreSQL、SQLite** 连接及目录，配置人工凭据、TLS、默认库与超时。
- 浏览数据库、表、列、主键、默认值和注释，查看或复制 DDL。
- 分页浏览表数据，按可编辑条件修改单元格或设为 NULL，核对保存结果与截断提示。
- 按数据库类型与权限新建库表、设计列、重命名、复制结构或数据、清空及删除对象。
- 在多标签 SQL 编辑器中执行查询，使用只读模板、查看历史和实际影响行数。
- 导出查询结果、数据库结构或 SQL 结构文件。
- 分别管理人工权限和 AI 权限，按语句分类选择允许、转提案或拒绝，设置结果行数、字节与超时预算。
- 配置并验证 AI 账号；支持相应条件下的 MySQL 平台托管账号下发。
- 管理项目关联、用户授权、会话、事务状态与摘要审计；查看 AI SQL 提案并由人工核对处理。

AI 提案表示待人工处理的 SQL。数据库结构或数据操作是否可执行，同时受当前策略、对象范围和数据库账号实际权限约束。

### 13. 缓存库管理

- 管理 Redis 连接、目录、默认 DB、TLS、账号与超时；按支持的配置通过 SSH 隧道连接。
- 按 DB、Key 模式、类型和前缀浏览，刷新、加载更多并打开多个 Key 标签。
- 查看和编辑 **String、Hash、List、Set、ZSet、Stream**；处理字段、成员、分值和消息内容。
- 新建、重命名、删除 Key，设置 TTL，使用 UTF-8 / Base64 及字符串 JSON 格式化。
- 通过命令控制台执行受控 Redis 命令，查看命令历史摘要。
- 进行频道发布、普通订阅和模式订阅，查看消息并取消订阅。
- 查看受限运行指标与脱敏慢日志，处理返回结果截断保护。
- 配置 AI 独立 ACL 账号或已有账号、允许的 DB、Key / 频道前缀及操作类别，验证实际可用范围。
- 管理项目关联、用户授权、AI 委派、会话与审计，并让 AI 在指定范围完成缓存任务。

### 14. 设置

- 查看云端账号资料、有效期、云空间用量，修改密码或退出账号。
- 查看当前服务、实例、客户端、构建、API 与契约版本。
- 配置本机 MCP 的默认项目、授权项目白名单、权限预设和工具能力。
- 选择 stdio / Streamable HTTP、AI 客户端、缓存连接白名单和最大连接数；启动、停止并生成客户端配置。
- 查看网关、外部客户端、工具与对象访问的分层接入诊断。
- 调整 Markdown 字号、显示偏好、常用入口与工作体验，清理本机最近访问记录。
- 查看模块权限引导、连接通道与本机体验度量，按需复制诊断或清空记录。

### 15. 意见反馈

- 选择反馈分类，填写问题或建议，附操作步骤、预期、实际、时间和错误码。
- 添加、预览和移除截图，提交后查看结果。
- 配合 Local API 的脱敏诊断摘要，提供能够复现的故障信息。

## Local API 功能介绍

Local API 主要用于管理当前服务实例，共有以下 9 个模块。

### 1. 服务状态

- 查看进程运行、服务就绪、账号授权和成员可用性。
- 启动、停止、重启服务，跟踪后台任务、进度、错误与可重试状态。
- 检查健康、就绪与元信息连接，查看异常恢复入口。
- 查看桌面活动连接、MCP 会话数、数据库与附件占用、Schema、契约与 TLS 等信息。

### 2. 初始化与恢复

- 完成首次初始化，选择并检查本机数据目录。
- 按本机使用、内网共享或反向代理场景配置监听地址、端口、TLS 与自动启动。
- 跟踪实例激活、Schema 迁移、初始化和失败恢复状态。
- 在新机器导入实例迁移包，按预检和当前授权完成恢复。

### 3. 客户端连接

- 刷新可访问地址，生成并复制提供给 Desktop 的连接信息。
- 查看公开证书与 SHA-256 指纹，帮助成员核对自签名连接。
- 查看桌面连接额度、授权状态、客户端、用户、来源地址、连接时间和最近心跳。
- 对不再需要的桌面租约执行吊销，释放相应连接占用。

### 4. 存储与备份

- 查看本机数据库、附件和备份目录的容量、文件数与完整性结果。
- 创建备份，选择附件、压缩方式和保留策略，跟踪备份任务。
- 对已有备份预检，核对实例、Schema 和恢复范围后执行恢复。
- 导出带口令保护的实例迁移包，用于迁移本机数据、身份和凭据保护材料。

### 5. 服务器安全

- 查看 Vault 凭据保护状态、健康与指纹。
- 导出、导入 Vault 恢复包，并核对恢复结果。
- 配置服务器、用户和实例的远程会话配额。
- 设置终端输出与审计记录保留期，管理服务器管理员。
- 查看活动远程会话及其所有者、目标、状态和租约。

### 6. 用户与权限

- 添加、编辑、启用或停用具有云端身份的实例用户。
- 查看显示名、账号 ID、本地用户 ID、活动状态与连接资格。
- 查看云端项目授权说明；如存在本机历史项目，可按权限查看其成员和角色。
- 区分实例访问资格与云端项目成员，协助处理“能登录但不能连接”或“能连接但看不到项目”的问题。

### 7. 诊断日志

- 运行宿主与服务诊断，查看通过、警告、失败项和错误码。
- 检查服务事件、实时连接、游标同步与断线后的事件补拉。
- 复制脱敏错误摘要，预览并导出诊断报告。
- 结合请求 ID、任务 ID、版本和时间定位故障，修复后重新检查。

### 8. 关于与更新

- 查看程序、构建、契约、Bridge、Schema 和平台版本。
- 查看当前版本提供的更新渠道、发布说明、兼容影响与升级能力。
- 当发行渠道提供升级操作时，执行预检、备份确认、跟踪更新与迁移，并按满足条件的入口处理回滚。

实际可升级版本、在线更新入口和回滚条件取决于发行渠道及当前部署状态。

### 9. 云端账号

- 登录本包预设云端，查看当前账号、设备与权益状态。
- 进入主界面继续初始化或日常维护。
- 修改密码、退出并重新建立账号会话。
- 配合实例激活与授权检查，处理账号到期或登录异常。

## AI 接入与协作方式

### 支持的工作方式

平台通过 **MCP（模型上下文协议）**，将当前账号获准访问的项目、内容和操作能力提供给 AI。

| AI 能力 | 可做的工作 |
| --- | --- |
| 项目与知识内容 | 读取项目背景，维护导图、节点、关系与节点 Markdown 说明。 |
| 文档与表格 | 读取和编辑获准对象，整理章节、编写公式、生成汇总并回读结果。 |
| 研发上下文 | 读取目录绑定、索引、逻辑线及已发布规则，协助本机开发与验证。 |
| 脚本与流程 | 编辑说明、参数、源码与流程图，按授权运行并读取结果。 |
| 服务器 | 发现项目关联资产，执行获准远程命令与文件操作，获取输出。 |
| 数据库与 Redis | 读取连接上下文，在有效策略内查询或处理数据，读取结果并关闭会话。 |

### 适配的 AI 客户端

设置页提供 Codex、Cursor、Claude Code、TRAE、Qoder IDE / CLI、Qwen Code、Kimi Code CLI、Cherry Studio、VS Code + GitHub Copilot、Cline、Gemini CLI、JetBrains AI Assistant 和 Zed 的配置模板。

可选择 **stdio** 或 **Streamable HTTP**，并启用多个客户端。具体接入格式与兼容性以所选客户端版本为准；HTTP 网关仅服务于 Desktop 所在系统的本机客户端，WSL、容器或远程窗口需要核对其网络环境。

### 接入步骤

1. 保持 Desktop 运行、云端登录有效、Local API 连接在线，并选择目标项目。
2. 在“设置 → AI 接入”选择默认项目和授权项目白名单。
3. 选择任务所需的基础权限和文档、表格、服务器、数据库、缓存、脚本或流程工具能力。
4. 选择客户端与传输方式，启动网关；复制软件生成的完整配置并合并到 AI 工具设置。
5. 在 AI 工具中重载 MCP，先确认实际工具列表，再读取一个指定项目或对象。
6. 完成一次小范围操作并回读，在 Desktop 查看真实内容、版本或运行结果。

修改白名单、能力或传输等网关参数后，应重新生成配置并重连。MCP 工具是否可用，以当前服务实际提供的工具和有效权限为准。

### 交给 AI 或复制 ID 给 AI

两种方式都可以：

- **交给 AI：** 在对象面板填写目标、范围和验收，复制完整任务到 AI 工具；可按页面能力另存为项目任务说明。
- **复制 ID 给 AI：** 从项目、文档、表格、导图、脚本、流程或资产页面复制 ID / Content ID，附上具体任务直接发给已接入 MCP 的 AI。

可以从下面的提示开始：

> 请使用协作平台 MCP，在项目【项目 ID】中处理对象【对象 ID 或 Content ID】。先读取最新内容、修订和有效权限。目标是【要完成的工作】，范围是【允许修改的位置】，验收要求是【预期结果】。执行后回读并报告实际变化、修订或运行 ID；缺少权限或需要人工处理时说明具体入口。

面板复制、保存任务说明、网关启动，分别代表任务交接或连接状态。完成工作还需在 AI 工具执行，并检查实际保存内容或运行结果。

## 典型工作流程

| 场景 | 推荐路线 | 结果检查 |
| --- | --- | --- |
| 建立团队项目 | 登录与服务连接 → 产品与项目 → 项目成员 → 建文档与导图。 | 成员能访问同一项目，目标、范围与里程碑明确。 |
| AI 整理知识材料 | 文档 / 表格授权 → AI 接入 → 交给 AI 或复制 ID 给 AI → 刷新与版本比较。 | 正文、公式与汇总真实保存，差异和数据口径正确。 |
| 梳理业务与验收 | 项目导图 → 功能与规则节点 → 节点说明 → 关联文档、表格或流程。 | 节点层级、关系、引用与验收内容一致。 |
| AI 辅助开发 | 绑定本机仓库 → 目录与索引 → 边界、配置集和 Skills → AI 本机修改代码 → 测试与上下文更新。 | 改动存在于正确仓库，实际测试有结果，相关说明与源码位置同步。 |
| 自动化测试与压测 | 脚本与参数 → 单次运行 → 组合流程 → 调试 / 断点 → 小规模压测 → 运行分析。 | 核对运行 ID、当时修订、节点输出、错误和延迟指标。 |
| 运维与数据处理 | 建资产 / 连接 → 人工验证 → 项目关联与授权 → AI 账号和策略验证 → 执行并回读。 | 目标主机、库或 DB 正确，实际影响符合要求，本任务会话已关闭。 |
| 服务备份与换机 | Local API 备份 → 完整性检查 → 导出实例迁移包 → 新机导入 → 重新登录与连接检查。 | 本机身份与数据恢复正确，服务就绪，成员可正常连接。 |

## 权限、数据与运行结果

### 权限如何生效

平台分层控制 **云端账号与权益 → 实例访问 → 项目成员 → 资源目录 / 资产授权 → AI 委派 → 对象或执行策略**。

- 管理员可配置资源，但 AI 操作仍需相应委派与账号验证。
- 文档和表格需核对目录权限及对象“允许 AI 编辑”；脚本和流程需核对有效执行权限与底层脚本权限。
- 服务器、数据库和 Redis 还需项目关联、凭据及有效策略；工具可见不代表任意资产可操作。
- 部分模块需要管理员先启用；版本和本机显示设置也会影响入口。

### 数据与备份的范围

| 数据或对象 | 保存与维护方式 |
| --- | --- |
| 云端项目及其协作内容 | 由云端服务管理；Local API 的本机备份不包含云端最新项目内容。 |
| 本机实例与配置 | 在 Local API 数据目录维护，通过“存储与备份”检查、备份与恢复。 |
| 本机源码仓库 | 保留在实际项目目录；平台保存绑定、目录、分支、符号等上下文元数据。AI 读取源码仍需满足实际访问权限。 |
| 实例迁移包 | 用于跨机器迁移本机身份、数据及凭据保护材料，导出时设置口令并核对范围。 |
| Vault 恢复包 | 用于凭据保护恢复，与完整实例迁移包的用途和范围不同。 |
| 外部服务器、数据库与 Redis 数据 | 保存在对应目标系统；操作配置和真实业务数据需分别管理与备份。 |

### 怎样判断工作完成

- 内容修改后重新打开或回读，检查正文、公式、层级、版本与差异。
- 命令、脚本和流程应有最终状态、输出、退出码或运行 ID；超时后使用原 ID 查询结果。
- 数据写入后检查实际目标与影响范围。删除、取消或断开连接不能自动撤销已经发生的外部写入。
- 完成服务器、数据库、Redis 任务后，关闭自己创建的会话与订阅；退出 AI 客户端不等于所有资产会话已释放。

## 常见问题与帮助

| 问题 | 优先处理 |
| --- | --- |
| Desktop 无法连接 | 检查 Local API 就绪状态、实际地址、端口、网络与证书；异机不要使用回环地址。 |
| 登录成功却看不到项目 | 核对云端账号及项目成员授权，再刷新并选择项目。 |
| 菜单或按钮不可用 | 检查模块开关、角色、目录 / 对象权限、当前项目与工作体验设置。 |
| MCP 已启动但 AI 调用失败 | 重载最新配置，检查外部客户端连接、实际工具列表、对象 ID 与授权。 |
| AI 能读不能写或运行 | 核对项目写权限、AI 委派、对象编辑开关、执行权限及资产策略。 |
| 脚本缺包或无法启动 | 使用真实 Desktop，在依赖管理检查随包 Python 与依赖；便携包需保留 `runtime/`。 |
| 保存冲突或运行超时 | 读取最新版本再合并；保留原运行 / 命令 ID 查询，避免重复操作。 |
| 恢复后云端内容没有回退 | 检查恢复范围，本机实例备份与云端项目数据分别管理。 |

完整的图文操作步骤见 **Desktop → 使用说明**。服务异常可在 **Local API → 诊断日志** 生成脱敏摘要；需要反馈时，在 **Desktop → 意见反馈** 提交模块、步骤、预期、实际、发生时间和错误码。
